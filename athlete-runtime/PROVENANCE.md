# Athlete source

These ten runtime files are unmodified copies of `apps/athlete/` from
`reflectprotect123-max/strengthside` at commit `6db0b96e`.
The coach integration lives outside this directory. Compare these files against
that commit before updating; library compilation and logger behavior must move together.

This is an isolated local preview, not a Supabase assignment integration.
The upstream compiler currently defaults reps to 8 (or 8–12 for reps_range)
and does not accept a prescribed load. Its load adjustment is a demo rule.
